# Gladiator Simulation with Binary Search Tree (Java)

## Overview
This project is a Java-based simulation system that models duel interactions between different cities.  
The system manages city populations and selects duel participants based on specific rules and constraints.

## My Contribution
Implemented the core logic in `Coliseum.java`, including:
- Binary Search Tree (BST) operations for managing cities in the game
- Recursive algorithms for searching, inserting, and deleting nodes
- Duel selection logic with multiple constraints (age, parity, and city restrictions)
- Dynamic updates of populations during simulation

## Key Features
- Efficient city management using BST
- Recursive traversal for selecting duel participants
- Handling of edge cases when populations become empty
- Simulation of duel outcomes and city elimination

## Tech Stack
- Java
- Data Structures (Binary Search Tree)
- Recursion
- Object-Oriented Programming (OOP)

## Highlights
